# gitlost.io — The Lost Commit Repository

> *Where lost commits find value. Literally.*

A speculative, interactive web experience that simulates discovering Bitcoin rewards from abandoned Git commits. Built as a front‑end portfolio piece — no real crypto, just atmosphere, random rewards, and `localStorage` persistence.

## ✨ Live Demo

[gitlost.io](https://your-demo-link-here.netlify.app) — *if hosted*

## 🧠 Concept

`gitlost.io` imagines a hidden archive of every commit that never made it to `main`: half‑written features, angry merge resolutions, desperate `"fix stuff"` messages. The site randomly rewards visitors with satoshis (simulated) based on a **Proof of Lost Work** — the more you seek, the more the void might give.

## 🎮 Features

- **Mysterious terminal UI** with glitch effects and live log output  
- **Random satoshi rewards** (28% chance per “seek”) with rare bigger payouts  
- **Persistent wallet** using `localStorage` – balance survives page reloads  
- **`git reset --hard` button** to wipe your found balance (with confirmation)  
- **Welcome reward** – sometimes the site gifts you satoshis just for visiting  
- **Dark, cyber‑git aesthetic** with animated cursor glow

## 🛠️ Tech Stack

- HTML5 / CSS3 (custom animations, flexbox, glassmorphism)  
- Vanilla JavaScript (no frameworks, no dependencies)  
- `localStorage` for wallet persistence  
- 100% client‑side — ready for GitHub Pages, Netlify, or any static host

## 🚀 Getting Started

1. Clone or download the `index.html` file.  
2. Open it directly in your browser — no build step required.  
3. Click **"seek lost commits"** to start finding satoshis.  
4. Refresh the page; your wallet stays intact.  
5. To reset, click **"git reset --hard"**.
